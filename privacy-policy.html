Privacy Policy

How eBlock Transfer handles data inside your browser.

Short version: eBlock Transfer operates 100% locally on your device. We do not collect, transmit, store, or sell any personal data, browsing activity, analytics, or copied Elementor content on any external server.

1. Data Collection & Network Transmission

eBlock Transfer makes zero network requests. The extension contains no analytics SDKs, telemetry beacons, remote APIs, user accounts, or tracking scripts. Nothing you copy, edit, or browse ever leaves your browser.

2. Local Browser Storage

To synchronize copied Elementor blocks across tabs on different domains, the extension uses Chrome's built-in local storage API (chrome.storage.local) strictly on your computer to store:

  • eblock_enabled — your ON/OFF toggle preference.
  • eblock_history — up to the 10 most recently copied Elementor JSON block structures, block category (Full Page, Container, Section, Column, or Widget), source hostname, and local timestamp.
  • eblock_active_id — the identifier of the currently selected block in your Recent Blocks list.

This data remains exclusively within your local browser profile and is never synced to external servers.

3. Permissions Explained

  • Storage (storage): Required to save your ON/OFF state and recent block clipboard items locally in chrome.storage.local.
  • Host Access (http://*/*, https://*/*): WordPress sites using the Elementor editor can be hosted on any custom domain, subdomain, staging environment, or localhost. On non-Elementor websites, the script performs a lightweight check for Elementor's editor objects and immediately stops without reading or altering page content.

4. Data Control & Deletion

You have full control over your local data at all times:

  • Click Clear inside the extension popup to immediately erase all stored blocks.
  • Switch the header toggle to OFF to pause clipboard bridging on all tabs.
  • Uninstalling eBlock Transfer from your browser permanently deletes all associated local storage entries.

5. Third-Party Sharing & Chrome Web Store Compliance

Because we do not collect any user data, we never sell, rent, or transfer user data to third parties, never use data for advertising or creditworthiness, and fully comply with the Chrome Web Store User Data Policy, including the Limited Use requirements.

6. Changes to This Policy

If future updates introduce optional features that affect how data is handled, this Privacy Policy will be updated prior to release with a revised date at the top of this page.
